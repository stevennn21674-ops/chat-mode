Chat Mode

Viewer chat that floats over your screen and reacts to what you are doing.

Offline mode blocks the comment service and web lookups. If the PC has no internet, chat stays offline until the connection returns. Game mode keeps the overlay above borderless fullscreen. A true exclusive fullscreen game can still cover it: use borderless or windowed fullscreen (Roblox is usually borderless; Shift+F11 or Esc, Settings, fullscreen).

Uses the Windows default until you pick another device. Virtual cables and stereo mix are skipped unless you pick them. Speech stays on this PC.

Hold is the default and works while a game is focused when the hook is running. Key repeat is ignored. Toggle starts and stops on each press. Always listening transcribes when it hears you and stays quiet when the room is silent. The fallback, if the hook cannot start, is Alt plus your talk key so the letter still reaches the game.

    If the mic stays quiet, open Windows Settings > Privacy > Microphone and allow desktop apps. The overlay only says Audio error. The reason is written here and in voice-debug.log.

    Hear computer audio is on by default. The last 18 seconds of sound from this PC are transcribed here and added when you press ` or finish talking. Silence is skipped, and it does not make its own request.

    Comment service

    On sends chat to the service with your key, model, and eco limits. Off keeps chat on this PC. Local brain, below, can read what you say without a key. The built-in lines are used when that model is off or unavailable.

    On by default. The screen is sent only when you press `. Unchanged screens are skipped, and calls stay under the hourly cap.

    Local brain (offline understanding)

    No model is in the installer. The first time this is turned on, Settings asks before downloading a Qwen 0.5B file: Q4 is about 469 MB, Q8 is about 644 MB. It reads the mic, on-screen text, colors, motion, and the window title on this PC. It cannot see the picture the way AI mode can. Ban commands still use the built-in parser.

    Light waits longer and uses one CPU thread. Heavy answers sooner and uses more CPU. If the PC is already busy, chat falls back to the built-in lines. Smarter brain is an optional Qwen2.5-1.5B Q4 download of about 1.04 GB. Q4 and Q8 are both downloads. Nothing is packed into the installer.

    The chat follows the newest line. Scroll up to pause that, then scroll back to the bottom or use Jump to latest. Turn auto-scroll off above to leave the list where you put it. The wheel over the chat scrolls it. Clicks still change speed, and a right-drag still moves the window.

    Left click slows, right click speeds up, and a right-drag moves the chat unless position is locked. The speed meter stays on the overlay. Slower and Faster are also in the tray.

    Performance

    Low is the default. It turns off computer-audio transcription and samples the screen slowly, not every second. Balanced transcribes computer audio about every 45 seconds and skips silence. High is about every 30 seconds. If CPU stays above about 70% for 10 seconds, or the overlay frame rate drops, background work backs off on its own.

    On by default. Turn it off only if the chat feels smoother that way. It applies the next time Chat Mode starts, because Windows applies it to the whole app.

    Screen activity

    The app looks at a tiny thumbnail. It notices motion, cuts, darkness, flashes, and the window title. No picture is uploaded. It pauses while you are idle, when a game is focused and the picture is not changing, when the CPU is high, and on battery if that box is on. Low performance mode waits longer than one second between looks.

    Auto vision sends a real screenshot only after a big change, and only while AI mode is on. The hourly cap is strict. Leave it off to stay on the local analyzer.

    Alerts

    Sounds are short tones made in the app. Messages stay kid-friendly. A donation also bumps the viewer count and gets a thank-you in chat.

    Real chat

    Twitch uses anonymous IRC, so no login. YouTube tries the public live chat page first. That unofficial endpoint can break. A Data API key is the stable option and is encrypted on this PC. Offline mode disconnects both. Real only stops the idle fake crowd and fake alerts while a chat is connected. Screen-activity lines and backtick or V reactions still run.

    Press ` to send the screen. Pause from anywhere with Ctrl+Shift+F8. Hold V and say ban, timeout, ban him, the last guy, the spammer, or everyone.

    Custom viewers

    Saved on this PC. Mods can answer ban commands. Haters stay light. AI mode and local brain use the description. The built-in lines use the sliders and catchphrases.

    Relay

    Leave this blank to use the built-in connection. A relay sends comments through a server you control.

    Controls

    • Left click slower chat
    • Right click faster chat
    • Right-drag move the chat, unless position is locked
    • Corner drag resize
    • ` send the screen
    • Hold V talk
    • Ctrl+Shift+F8 pause capture
